# Jobo contributions have moved

Use **[`jobo-main`](https://github.com/Lcub3d/dayGLANCE/tree/jobo-main)** for new Jobo development and as the target of Jobo pull requests. Read the [current contribution guide](https://github.com/Lcub3d/dayGLANCE/blob/jobo-main/CONTRIBUTING.md) and [maintenance record](https://github.com/Lcub3d/dayGLANCE/blob/jobo-main/docs/jobo-maintenance.md).

This `main` branch is a legacy code/reference branch and entry page, not the active feature-development line. Original upstream PR source branches remain preserved; do not add unrelated new work to them or close the PRs as part of this transition.

The old contribution guide is retained as [CONTRIBUTING.upstream.md](CONTRIBUTING.upstream.md) for reference. The original MIT license and authorship remain in place.
