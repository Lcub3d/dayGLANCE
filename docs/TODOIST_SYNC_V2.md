# Todoist 同步 V2（测试版）

## 如何使用

在 **设置 → Todoist 同步** 填写个人 API Token，点“连接并加载预览”。连接只是只读检查，不会导入任务，也不会向 Todoist 写入。

选择同步方式后点 **立即同步**；**不需要先开启自动同步**。新安装默认“今天的任务”，默认放入今天页面。升级自旧版会保留原项目、标签、优先级和收件箱设置，不擅自扩大范围；需要在方式下拉框主动切换“今天的任务”。

Token 仅在本次会话保存，不要发到聊天、日志或提交仓库。关闭应用后可能需要重新连接；这不是 OAuth，也不是后台常驻服务。应用关闭后不会继续同步。

## 四种方式

| 方式 | 范围和行为 |
| --- | --- |
| 今天的任务 | 根据 Todoist 任务日期（不是 deadline）选择今天；忽略高级筛选。可选择包含逾期任务。 |
| 全部未完成任务 | 明确选择后拉取全部活跃任务，忽略高级筛选。 |
| 按条件筛选 | 项目、标签、P1–P4；项目包含子项目；标签任选/全含；条件组 AND/OR；可再限制今日。全部条件留空不导入。 |
| 单向镜像（实验性） | 在全量、今日或筛选范围内，以 Todoist 为准覆盖关联任务内容和完成状态；日期/时间另有开关。不是完全双向同步。 |

普通拉取可选“今天”“Todoist 任务日期（无日期进收件箱）”“收件箱”。普通模式保留已在 dayGLANCE 手动修改的时间块；更改导入位置不会强行重排这些时间块。时间按 Todoist 账户时区解释，缺失时使用运行设备时区。今日的边界是该时区午夜，不是 dayGLANCE 自定义工作日分界。

## 同步结果

界面显示读取数、匹配数、新导入、更新、移入回收站、恢复、未变、已在本地移除、来源缺失，以及日历/收件箱中的关联未完成任务数。

预览数是当前缓存的匹配数，点“刷新预览”可更新，仍不导入。最后导入结果保留自己的时间戳，预览成功不等于导入成功。零匹配、任务已存在、本地曾删除、来源缺失和网络失败会分别提示；不能把“读到 0 条”简单称为同步成功。

## 镜像安全边界

进入镜像或更改镜像范围/规则、日期开关后，需要重新确认提示。镜像默认关闭完成回写。仅处理同一 Todoist 账户的关联副本，不会修改 dayGLANCE 原生任务或其他账户的任务。

明确的 Todoist 删除记录、仍存在但移出筛选范围的任务，其本地副本移入 dayGLANCE 回收站，不永久删除。自动移出的副本再次符合范围时可恢复；手动删除或已清空回收站的条目不会自动复活。恢复只恢复本地副本，不在 Todoist 重建任务。

**完整快照中缺失的任务，不等于已删除或已完成。** 这种情况保留副本并显示“来源缺失”，不做猜测；首次连接前的完成历史不会批量补导。因此镜像是有保护边界的单向同步，不承诺两个数据库逐条完全一致。

保留远程明确完成的本地历史。Todoist 项目/标签作为关联来源元数据更新，不创建同名 dayGLANCE 项目或标签体系。循环任务保留 Todoist 来源语义，不生成第二套 dayGLANCE 循环模板；请在 Todoist 中完成循环任务。

普通模式可单独启用原有的普通叶子任务完成回写，只允许 item_close；不回写撤销、标题、时间、标签、项目或删除，不导出原生任务。循环、含活跃子任务的父任务、分配给他人的任务不回写。建议仅一台设备启用写回；Web Locks 不可用时禁用写回而非不安全抢锁。

## 实现与验证

核心：`src/todoist/core.js`；网络与凭据：`src/todoist/client.js`；常驻调度：`src/hooks/useTodoistSync.js`；界面：`src/components/TodoistSettings.jsx`；文案：`src/todoist/strings.js`。

运行 `npx vitest run src/todoist`、`npm run lint`、`npm test`、`npm run build`。Windows 工作流另外编译 Electron、生成并安装 NSIS 安装包，使用合成 Todoist API 进行界面冒烟测试并保存截图/日志。工作流结果才是对应提交是否通过的依据。

没有使用真实 Todoist Token 或操作个人任务。真实账户网络、代理、防火墙、Windows 现有用户配置、Android/iOS 原生桥仍需实际环境验证。Windows 测试安装包未签名，安装前建议备份 dayGLANCE 数据；它沿用现有应用标识以支持覆盖安装，不是独立隔离的用户配置。
