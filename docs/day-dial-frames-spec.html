Enclosure, outlined at r=126 and r=153 with radial end caps — the gaps either side of the block band, so nothing else moves. Frame colour goes through muteDialColor and then sits below the block rims in weight, so the needle stays the brightest thing on the face.

Hub priority: a running task wins. Frame details appear only when nothing is scheduled, and then they mirror what GLANCE shows — name, span, and time still available inside the frame. The two dials above are the same day and time, one with a task running and one without.

Card: one entry titled "Frames" carrying the percentage, in the slot right of Routines, with the four-square outline mark, in the same line style as the other metric icons, and the same label styling as every other metric.

Hub title: same weight and size as a task title. Only the colour differs, and it uses the app's own muteDialColor rather than the softer ring treatment, so the title keeps its strength while the enclosure stays quiet. The four-square mark sits before it.
