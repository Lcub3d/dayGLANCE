- 默认页最大宽度 `1180px`，最小高度 `480px`；主表面圆角 `12px`，header 内距上下 `24px`、左右 `32px`。
- 页面标题为 `22px / 32px / 600`；正文保留 `14px / 24px`，移动端策略输入为 `16px`。
- 默认页去掉愿望与愿景的占位提示，仅座右铭空白行保留占位文案；其他空白行仍保留。

## Taste DNA

以下条目描述可复核的设计取舍，不宣称审美结果符合预期。

### 1. 原生色彩与文字层级

- **Trigger**：规划页同时承载可编辑正文、状态入口和帮助信息。
- **Decision**：保留原有白色、灰阶、蓝色与橙色，正文使用 14px / 24px，状态胶囊仅使用语义红色与绿色。
- **Reason**：让文字层级和状态语义由已有 token 控制。
- **Evidence**：正文 computed style 为 14px；SWOT 使用红色胶囊，可测量愿景使用绿色胶囊。

### 2. 信息按需出现

- **Trigger**：详情帮助列和愿景解释会占用可编辑宽度。
- **Decision**：允许两列帮助整体收起，默认编辑区域移除愿望与愿景占位提示，仅座右铭空白行保留占位文案，其他空白行仍保留。
- **Reason**：把持续可见的信息限制在当前编辑所需范围。
- **Evidence**：帮助收起后 12 行愿景边界与表头均为 `x=792.322937`；默认页仅座右铭空白行保留占位文案，其他空白行仍保留。

### 3. 动作回退保持可追溯

- **Trigger**：拖拽删除和愿景编辑都会改变用户已保存结构。
- **Decision**：显示拖影，trash 删除后保留 Undo；保存愿景仍使用存储时长计算，UI 偏移单独处理。
- **Reason**：让删除可恢复，避免把显示坐标混入持久化数据。
- **Evidence**：真实鼠标删除测试愿望后 Undo 恢复同一愿景，拖影可见且 trash 保持在 sheet 内；两阶段 outside click 后重开仍为 `36@1y`、`52@2y`、`total=2`；`totalYears` 继续基于保存 durations。

### 4. 原生流程保持可取消

- **Trigger**：愿景可以继续进入原生项目创建流程，空白编辑也需要快速退出。
- **Decision**：项目按钮只预填原生创建表单；空新愿景用 Esc 关闭，取消项目表单返回规划页。
- **Reason**：让外部创建动作和本地编辑保持清晰的返回边界。
- **Evidence**：项目表单预填“阅读36本书”后取消返回；空新愿景 Esc 直接关闭。

### 5. 阶段编辑与原生流程

- **Trigger**：阶段值按需编辑，并可从愿景进入原生项目创建。
- **Decision**：只保存被触碰的阶段；支持空白阶段追加、相对单位循环与建议值；项目入口复用原生创建表单并保留取消返回。
- **Reason**：让阶段编辑、自动保存和外部创建动作保持清晰的返回边界。
- **Evidence**：未触碰的空白阶段不保存，手填第 3 年 `69` 后 outside save/reopen 为 `69@3y`；第 4 个空白阶段切换为 5 年后建议值 `100` 并自动保存；单位循环为 `5年 → 60个月 → 1825天 → 5年`；项目表单预填“阅读36本书”后取消返回。
